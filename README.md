# Telegram Daily Check-in

A simple Python script using Telethon to automatically click a daily check-in button in a Telegram chat/bot.

## Requirements

- Windows 11
- Python 3.10+
- Telegram account
- Telegram API ID and API Hash from https://my.telegram.org

## Installation

```bash
git clone <your-repository-url>
cd Tele-Daily-Checkin

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
